# IoT Module 4 — Tank Monitoring and Filling System

This repository contains the Module 4 IoT assignment for the **Tank Monitoring and Filling System** project.

## Project scope

The prototype integrates a Raspberry Pi Pico W, DHT22 sensor, HC-SR04 ultrasonic sensor, RGB status LED, tank alert LED, and a web-controlled pump indicator.

The project is being prepared as a **Wokwi virtual functional prototype** because a physical Raspberry Pi Pico W is not currently available.
